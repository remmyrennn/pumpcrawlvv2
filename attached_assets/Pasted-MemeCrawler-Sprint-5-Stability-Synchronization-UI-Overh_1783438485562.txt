Read and understand the entire repository before making any changes.

DISCOVERY ENGINE

Pump.fun is no longer considered a reliable production provider.

Refactor the discovery pipeline to use:

* DexScreener
* Helius

Keep provider architecture modular so future providers can easily be added.

Gracefully handle provider failures.

No provider failure should stop the scanner.

⸻

HELIUS

Use Helius as the primary Solana infrastructure provider.

Use it wherever appropriate for:

* RPC
* wallet analysis
* holder analysis
* token metadata
* transaction history
* deployer analysis
* ownership verification
* smart wallet analysis where beneficial

If any required Helius configuration is missing or invalid, ask me before proceeding.

⸻

DATABASE

SQLite remains the primary local database.

Whenever Supabase is available:

Automatically synchronize SQLite changes to Supabase.

If Supabase becomes unavailable:

Continue operating entirely from SQLite.

Queue synchronization automatically.

Synchronize automatically once Supabase becomes available again.

No user action should be required.

⸻

BROADCAST CHATS

TARGET_CHAT_ID must no longer be stored as configuration.

Broadcast chats must instead be stored in the database.

Create a full management system.

Allow:

* Add broadcast chat
* Remove broadcast chat
* List broadcast chats
* Enable/disable chats

Changes should persist automatically.

⸻

CONTRACT ADDRESS TRACKING

Whenever any user pastes a valid Solana contract address:

Private chats:
Automatically begin tracking.

Groups:
Automatically detect the contract address and begin tracking if permitted.

Track both:

* upward movement
* downward movement

Generate milestone alerts.

Milestones should trigger on meaningful percentage movements (including both gains and losses) while avoiding duplicate notifications for the same movement range.

Continue monitoring until tracking ends.
